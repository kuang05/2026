# CUMCM 2026 B 题求解工程

本目录保存 B 题的可复现实验与论文源稿。题目 PDF、附件和模拟器为上游输入；`资料`目录只用于方法线索，不作为本题数值结果来源。

## 目录

- `geometry.py`：角误差扇区、半平面裁剪、定位区域直径与最小覆盖圆。
- `offline_sim.py`：按附件规则生成全向/定向干扰源并模拟 HTTP 动作，用于策略回归测试。
- `robot.py`：连接真实模拟器的串行 HTTP 机器人；同一逻辑也可注入离线模拟器。
- `run_experiments.py`：离线 Monte Carlo、Q1/Q2 几何实验、敏感性分析。
- `benchmark_q3.py`：问题 3 新旧策略的同案例留出集与边界压力测试。
- `benchmark_q4_recovery.py`：问题 4 单示向线恢复策略的同案例配对测试。
- `analyze_run.py`：按移动、测量、无信号和失败清除分解单局日志。
- `paper.md`：由冻结结果撰写的中文论文源稿。
- `results/`：运行日志、表格、图和冻结数字。

所有实验固定随机种子并记录参数。正式测试已通过模拟器完成，当前材料已收到六份原始日志及其结果元数据。案例编码来自这些原始文件；清除数量和运行时间记录见 `formal_test_records.csv`。

问题 3 当前默认采用不含原点的正七边形极小极大连续覆盖，环半径与最坏最近距离均约 998.925 米；保留两条示向线发现策略、100 米交点试探、150 米扫描绕路阈值、多起点 2-opt 和 19.11 米覆盖半径的三角格兜底。本轮新增并默认开启：已发现频道的必无信号补测剪枝、保守可行域缓存、保证清除服务区域内的短路选点，以及预算感知退化和退出保护。未知频道的完整覆盖不变。推断无信号与真实测量分开记录；汇总记录完整配置、源码哈希和移动/检测/切频/清除耗时。

新布局先经 36 个场景筛选，再以 60 个新场景独立留出验证；相对原中心加七环点布局平均降时 1.5796%，95% 区间为 0.7879%-2.3717%。完整终版再在 `results/q3_final_policy_holdout_v2/` 的 50 个新场景上与本轮开始前源码端到端配对：逐场景相对时间降幅均值为 4.1550%，分层配对 Bootstrap 95% 区间为 2.7846%-5.3846%，42/50 局更快，三组策略均全部清除；平均每源时间由 310.642 秒降至 297.205 秒。布局与完整策略的百分比来自不同对照，不能相加。全部数据为离线合成实验，不替代官方成绩。

有限步总时间调度已实现为可选实验 `--q3-joint-time-routing`，因筛选中的增益很小而真实计算明显变慢，默认关闭。消融开关为 `--no-q3-skip-impossible-rechecks`、`--no-q3-service-region`，关闭二者可保留本轮前的主要动作策略（缓存和资源保护仍保留）。运行目录必须是新目录，以免追加式事件日志混入旧记录。

Q3 材料以 `python build_artifacts.py --q3-only` 更新；不传参数也只同步 Q3，避免覆盖其他题。生成前核验当前配置、源码哈希与留出验证一致。当前图为 `artifacts/figures/fig_q3_current_cover`、`fig_q3_improvement`；方法、写作包、镜像目录、支撑代码和 Q3 冻结记录由同一入口生成。旧综合图中的 Q3 和旧离线性能图不应再用于当前版论文。`--q1-validation-only` 保留原 Q1 流程；历史全量重建仅在显式 `--legacy-full-build` 下运行，不建议用于当前提交。

所有新增实验通过 `benchmark_q3_improvements.py` 复现，基线必须提供本轮前的独立源码目录；离线实验不改写正式成绩记录。正式测试已导出三次问题 3 和三次问题 4 的原始日志，文件名保持模拟器生成的名称；日志正文为加密格式，清除数量、清除比例、平均定位清除时间和程序运行时间须以模拟器结果页或官方解密汇总核验，不能由离线实验或元数据起止时间差代替。

问题 4 默认采用通过连续覆盖充分性检验的 21 点正向包围布局和三条示向线发现策略：原点、半径 996 米的 8 点内环及包含目标圆域的 12 点外环。定位阶段使用 10% 信息量下限的近路候选；当定位域半径不超过 100 米时，先用示向线交点尝试快速清除；扫描途中只插入增量路程不超过 200 米的清除点。失败后仍保留测向、阴影恢复、确定性定位域和 19.11 米覆盖半径的三角格兜底。旧 25 点布局可用 `--q4-layout compact25` 做回归对照。

当前默认还启用三个不改变保证层的细化：联合正负观测只删除严格不可能的位置单元，有限源假设只用于按预计虚拟时间重排测点，保证清除域内选择进出路程更短且经全部顶点复核的服务点。当前源码的 55 局分层重放与另一组 24 局共享误差压力集均保持 100% 离线合成清除，配对平均总时间降幅分别为 1.157% 和 1.126%。消融结果保存在 `results/q4_ablation_current_v2/`，冻结材料由 `python build_q4_artifacts.py` 生成。上述数字均为离线算法回归，不是官方成绩；正式测试原始日志已保留，最终统计字段仍以模拟器结果页或官方解密汇总为准。
